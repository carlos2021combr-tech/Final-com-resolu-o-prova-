# Sistema Acadêmico – Aula 11 (JSON, Web Storage e LocalStorage)

Programação Web I – UNIVEST. Abra `index.html` no navegador.

- `js/dados.js`: dados iniciais · `js/storage.js`: salvar/carregar/remover · `js/app.js`: DOM, eventos e regras.
- Alunos: cadastro, lista, busca, filtro, detalhes, remoção, alteração de status, persistência e restauração.
- Cursos, matrículas e usuários também são persistidos. Respostas em `RESPOSTAS.md`.
